# Contributing Guidelines

All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How to Contribute

1. **Reporting Bugs**: Open an issue describing the bug, steps to reproduce it, and expected behavior.
2. **Suggesting Enhancements**: Feel free to open an issue to discuss new features or improvements.
3. **Pull Requests**: 
   - Fork the repository and create a new branch.
   - Make your changes and commit them with clear, descriptive messages.
   - Open a Pull Request referencing the issue or feature being addressed.

Thank you for contributing!
